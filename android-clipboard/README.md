# クリップ棚（Android）

Android でも、**Mac・iPhone・Windows とクリップボードをやり取りする**アプリ。AirDrop や Handoff の代わりになる。
同じ中継サーバー（`clip-relay/`）を使うので、どの端末から送ったものも、ほかの端末に届く。

- 写真・スクショ・テキストを、**端末で暗号化してから**送る。中継サーバーは中身を読めない（24時間で消える）。
- **バックグラウンドで待ち続ける**（通知に「つながっています」と出る）。Mac などから送ると、そのまま**クリップボードに入る**ので、貼り付けるだけ。
- 必要環境: Android 8.0 以降。
- **まだ実機で試していない。** GitHub の環境で、暗号・通信（Java の部分）のテストと APK のビルドが通ることだけ確認している。

## 入れ方（最初の1回）
1. Mac のクリップ棚を最新版にする（メニューバーのアイコン →「最新版にアップデート…」）
2. Android の Chrome で、[最新版のページ](https://github.com/skmax3/Research_tools/releases/tag/clipshelf-android-latest)を開いて、`ClipShelfAndroid.apk` をダウンロードする
3. ダウンロードした APK を開く →「この提供元のアプリを許可」（初回だけ聞かれる）→「インストール」
   - 「Play プロテクト」の警告が出たら、「詳細」→「インストールする」（Google Play の外のアプリのため。自分で作ったアプリなので問題ない）
4. アプリを開き、通知を「許可」する
5. ペアリングする
   1. Mac のクリップ棚のメニューバーのアイコン →「iPhone との接続…」
   2. 「**Windows・Android アプリ用のコードをコピー**」を押す
   3. そのコードを Android に送って（メモや自分宛てのメッセージなど）、アプリの欄に貼り付けて「ペアリング」。コードには鍵が入っているので、自分の端末以外には送らない
6. 「電池の最適化から除外する」を押す（機種によっては、バックグラウンドの待ち受けが止められるため）

## 使い方
| やりたいこと | 操作 |
|---|---|
| ほかの端末から届いたものを貼る | 届くと通知が出て、そのまま**貼り付けられる**（設定「届いたら、すぐクリップボードに入れる」がオンのとき）。通知の「コピー」ボタンや、アプリの「届いたもの」からも取り出せる |
| 写真・スクショ・テキストを送る | ほかのアプリ（ギャラリー・Chrome など）の**共有メニュー**で「クリップ棚」を選ぶ。複数枚もまとめて送れる |
| コピーしたものを送る | **クイック設定のタイル**「今のコピーを送る」をタップ（画面の上から引き下げて、鉛筆のアイコンで編集 → タイルを追加）。アプリのアイコンの長押し、通知のボタン「今のコピーを送る」からも送れる |

送れるのはテキストと画像（1件 8MB まで。大きい画像は、長辺 2560px の JPEG にして送る）。動画・ファイルは未対応。

### なぜ「コピーしたら自動で送る」にしていないか
Android 10 以降は、**クリップボードを読めるのは、前面にあるアプリだけ**（バックグラウンドで、コピーを見張ることはできない）。そのため、タイル・通知のボタン・アイコンの長押しで、一瞬だけ前面に出て読む作りにしている。届いたものをクリップボードに**入れる**のは、バックグラウンドでもできる。

## 更新
GitHub の最新版ページから、新しい APK を取って、上書きで入れる。
署名の鍵が、ビルドのたびに変わる設定のままだと「署名が違う」と言われるので、その場合は、いったんアンインストールして入れ直す（ペアリングもやり直し）。
入れ直しをなくすには、GitHub の Secrets に、署名の鍵（`ANDROID_KEYSTORE_BASE64`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD`）を登録する。

## 開発メモ
- Java（Android の標準 API だけ。外部のライブラリは使わない）。ビルドは Gradle（Android Gradle Plugin）。
- 暗号・ペアリングコード・中継サーバーとの通信（WebSocket を含む）は、Android に依存しない Java（`core/`）で書いてあり、`tests/CoreTest.java` で、Web 版・Mac 版・Windows 版と同じ固定の値との一致を確かめる。ローカルの中継サーバーでの通信テストもある（`--online`）。
- ビルドは GitHub Actions（`.github/workflows/android-clipboard.yml`）。`main` に入ると、リリース `clipshelf-android-latest` に APK が置かれる。
- 構成:
  - `core/SyncCrypto.java` / `PairCode.java` / `MiniJson.java` / `RelayClient.java` / `WebSocketClient.java`: Android に依存しない部分
  - `SyncService.java`: バックグラウンドで待ち続ける（フォアグラウンドサービス）
  - `MainActivity.java`: 画面　`ShareActivity.java`: 共有メニュー　`SendClipboardActivity.java` / `SendTileService.java`: 今のクリップボードを送る
  - `Sender.java`: 暗号化して送る（画像の縮小・向きの補正）　`Clips.java`: クリップボードの読み書き　`ImageProvider.java`: 届いた画像を貼り付けられるように渡す
