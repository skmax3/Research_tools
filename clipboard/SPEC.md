# クリップボード — 仕様メモ

目的: Mac で、テキスト・画像・大きなファイルを「ためて、順番を決めて、まとめて取り出す」。研究用途（記号入力、表の変換、PDFからのコピー整形）に強くする。

状態: MVP（Mac 内部で使う版）を実装。Mac⇄iPhone の受け渡しは当面 Handoff で代用し、下の「保留」に調査結果を残す。

## 方針（2026-11 に変更）
- 当初は Mac⇄iPhone の受け渡し（中継サーバー＋端末側暗号化）を MVP にする予定だった。
  準備の手間（Cloudflare アカウント・GitHub への鍵登録）と、iPhone 側の手間（ホーム画面アプリと Safari の保存領域が別）を考え、
  **まず Mac 内部のクリップボードツールとして作る** 方針に変更した。
- サーバーなし・外部送信なし。データはブラウザ内（IndexedDB）にだけ保存する。ルート `CLAUDE.md` の「ツールはデータを外部送信しない」をそのまま守れる。
- Webアプリ（PWA）として `clipboard/index.html` 1ファイル。外部ライブラリなし。

## MVP でできること（実装済み）
- **追加**: ⌘V（テキスト・書式付きテキスト・スクリーンショット等の画像・Finder でコピーしたファイル）、ドラッグ＆ドロップ（複数ファイル）、ファイル選択、テキスト入力、「クリップボードから貼り付け」ボタン（iPhone 用）
  - 同じテキストをもう一度追加したら、重複させず先頭へ移動
  - Excel のコピー（表＋セルの画像が同時に来る）は表のテキストとして扱う
- **一覧**: 新しいものが上。番号表示。検索（`/`）
- **並べ替え**: ⋮⋮ をドラッグ（マウス・タッチ）、`⌥↑` `⌥↓`
- **取り出し**
  - クリック／Enter でコピー（テキストは書式付きのまま、画像は PNG）。`⌥`クリックで書式なし
  - カードを他のアプリへドラッグ（画像はサムネイルをドラッグ）
  - 「保存」でダウンロード。iPhone は詳細画面の「共有…」から写真やファイルに保存
- **順番に使う**
  - 順番コピー: 1件コピー → 相手のアプリで貼り付け → `Space`／「次をコピー」で次の1件（ファイルは対象外）
  - 番号付きで保存: 選んだものを `01_`, `02_` … の順番付きで1つの ZIP に（無圧縮、合計4GB未満）
  - まとめてコピー: 選んだテキストを並び順に、改行・空行・タブ・カンマ等でつないで1回でコピー
- **選択**: ⌘クリック・丸ボタン、⇧クリックで範囲、⌘A、Esc で解除。削除は「元に戻す」可
- **テキスト変換（詳細画面）**: 改行を整理（PDFのコピー）、英数を半角に、半角カナを全角に、余分な空白・空行の削除、表（Excel/CSV）→ Markdown / LaTeX / CSV / タブ区切り。変換すると自動でコピーされる
- **記号パレット**: φ ± ° μ Ω など。押すとコピー（入力欄にカーソルがあれば挿入）
- 同じブラウザで2つのタブを開いても内容が同期される（BroadcastChannel）

## 制約（Webアプリの限界）
- ⌘C した内容を裏で自動記録することはできない。この画面で ⌘V する操作が必要（自動の履歴が欲しい場合は Mac アプリ Maccy などを併用）。
- 他のアプリへ「貼り付け」まで自動で行うことはできない。順番コピーは「コピーまで」を自動化する。
- 一般のファイル（PDF等）はクリップボードに入れられない（ブラウザの制約）。ドラッグか保存で取り出す。
- Safari・ホーム画面アプリ・Dock に追加したアプリ・Chrome のアプリは、それぞれ保存場所が別。
- HEIC（iPhone の写真）は追加時に JPEG に変換して画像として扱う（元の HEIC も保持し「元のHEICで保存」可）。Safari は標準機能、Chrome は HEIF を自前で解析して WebCodecs（Mac のハードウェア HEVC デコーダ）で変換。変換できない環境ではファイル扱いに戻る。
- 貼り付け先に合わせた形式: コピーは PNG（Chrome がクリップボードに置ける画像形式は PNG のみ。ほぼ全アプリが受け付ける）、ドラッグ・保存・ZIP は JPEG。詳細画面から PNG / 元の HEIC でも保存できる。
- 裏で ⌘C を自動記録すること、他のアプリの上に下から出てくるパネルにすることは Web アプリではできない（ネイティブアプリが必要）。
- Safari で普通に開いている場合、7日間使わないとデータが消されることがある（Safari の仕様）。Dock／ホーム画面に追加して使うのがおすすめ。

## 保留: Mac⇄iPhone の受け渡し（調査済み・未実装）
2026-11 時点の調査結果。必要になったらここから再開する。
- **中継サーバー**: Cloudflare Workers ＋ Durable Objects（無料プラン可。1日10万リクエスト）を採用予定。
  - Supabase は無料プロジェクトが1週間使わないと停止するため不採用。
  - Cloudflare KV は反映に最大60秒かかるため不採用。
  - デプロイはリポジトリ内のコードを GitHub Actions で自動配置する。ユーザーの作業は、Cloudflare アカウント作成・APIトークン発行・GitHub Secrets 登録（`CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`）。
- **暗号化**:
  - QR で共有した秘密値から、AES-GCM の鍵と部屋IDを作る。サーバーは暗号文しか持たない。
  - 24時間で自動削除する。
- **ショートカット**:
  - ショートカットアプリには AES がないため、「URLを開く」で `#send=<コード>&t=<テキスト>` を渡し、ページ側で暗号化して送る。
  - `#` 以降はサーバーに送られない。
- **iPhone の注意**:
  - Safari の Web ページは QR 読み取り（BarcodeDetector）に未対応。
  - ホーム画面アプリと Safari は保存領域が別。そのため「カメラで QR → Safari でコードをコピー → アプリに貼り付け」の手順になる。
