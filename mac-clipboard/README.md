# クリップ棚（Mac アプリ）

⌘C したものを自動で記録し、**⇧⌘X で画面の下から履歴パネルを出して**、選ぶとそのまま元のアプリに貼り付ける Mac 用クリップボードアプリ。
Web 版（`clipboard/`）と違い、ネイティブアプリなのでバックグラウンドの記録・どこでも効くショートカット・自動貼り付けができる。

- データは `~/Library/Application Support/ClipShelf/` にだけ保存し、外部には送らない。
- 履歴は、ピン留め以外 **500 件まで・合計 1 GB まで**。超えたら、ピン留め以外の古いものから自動で消える（4K のスクショは 1 枚 5〜15 MB あるため）。
  今の使用量はメニューバーのアイコン →「履歴の容量」で見られ、上限は 500 MB / 1 GB / 2 GB / 5 GB / 上限なし から選べる。残したいものはピン留め（⌘P）する。
- 容量を手で空けたいときは、パネルの上の「**大きい順**」を押す。保存している大きさの順に並び、カードに大きさが出る。⌘クリック・Space・⇧← → で選んで、⌘⌫（または下の「削除」）を **2回押す**と、まとめて消える（間違い防止のため、1回目は確認の表示になる）。
- **古い画像は自動で軽くなる:** コピーしてから 7 日（メニューで 3 日 / 7 日 / 30 日 / しない から選べる）がたった画像を、PNG から JPEG（品質 88）に変える。新しいものは PNG のまま（貼ったときに劣化しない）。ピン留めしたものは変えない。透明な部分がある画像、JPEG にしても 3 割以上は軽くならない画像（単色の図など）もそのまま。変換は裏で行い、起動 20 秒後と 1 時間ごとに確かめる。変えるとファイルの拡張子が .png → .jpg になるだけで、履歴の内容は変わらない。メニューの「古い画像を軽くする」に、これまでに減った容量が出る。
- パスワードマネージャーが「記録しないで」と印を付けたコピーは記録しない。
- 必要環境: macOS 14 Sonoma 以降、Xcode（App Store から無料）。

## 使い方
| 操作 | キー・マウス |
|---|---|
| パネルを出す／閉じる | ⇧⌘X（メニューバーのアイコンからも開ける） |
| 選ぶ | クリック、← → |
| 貼り付け | ダブルクリック、Enter（⌥Enter で書式なし）、⌘1〜⌘9 |
| 複数選択 | ⌘クリック・⇧クリック・Space・カード右上の丸、⇧← → で連続、⌘A で全部（選んだ順に番号が付く） |
| 複数を貼る | Enter＝番号順に1件ずつ貼る（テキストの間は改行）／⇧Enter＝1回にまとめて貼る |
| 種類で絞り込み | 上のチップ（テキスト＝青・リンク＝紫・画像＝橙・動画＝ピンク・ファイル＝青緑で色分け。Finder でコピーした写真・動画もそれぞれの色になる）、Tab で切り替え |
| コピー元で絞り込み・並べ替え | アプリのチップ（件数の多い順）、「アプリ順」でアプリごとに並べる |
| 文字で絞り込み | 検索欄に入力 |
| テキストを変換して貼り付け | ⌘T または右クリック（PDF の改行整理、英数を半角に、半角カナを全角に、表 → Markdown / LaTeX / CSV / タブ区切り）。変換結果は履歴にも残る |
| ピン留め／削除 | ⌘P ／ ⌘⌫（右クリックからも可。複数選択中の ⌘⌫ は、2回押して確定） |
| 大きい順に並べる | 上の「大きい順」（容量を空けるとき。アプリ順とは同時に使えない） |
| 他のアプリへ渡す | カードをドラッグ |
| 閉じる | Esc（複数選択中は選択の解除） |

自動で貼り付けるには、初回に「システム設定 → プライバシーとセキュリティ → アクセシビリティ」で ClipShelf を許可する。許可するまでは「コピーまで」で、⌘V は自分で押す。

## URL スキーム（Logi Options+ などから呼ぶ）
`clipshelf://` で、ほかのアプリ・ボタン・ランチャーからパネルを開ける。パネルを開くだけで、URL だけで何かが貼られることはない（選んだときだけ貼られる）。

| URL | 動き |
|---|---|
| `clipshelf://open` | パネルを開く（⇧⌘X と同じ。絞り込みは「すべて」に戻る） |
| `clipshelf://open?kind=text` | 「テキスト」だけで絞り込んで開く |
| `clipshelf://open?kind=link` / `image` / `video` / `file` | リンク／画像／動画／ファイルだけで絞り込んで開く |

- `kind` が空・知らない値のときは、絞り込みなしで開く。知らないコマンド（`clipshelf://close` など）は何もしない。
- 貼り付け先は「直前に前面だったアプリ」。URL で開いて前面のアプリが変わっても、貼る前にそのアプリを前面に戻してから ⌘V を送る（Dock に出る通常のアプリだけを貼り付け先として覚える。Logi のエージェントなどは対象外）。
- 使えるようになるのは、`scripts/install.sh`（または「最新版にアップデート…」）で `/Applications/ClipShelf.app` に入れて、一度起動したあと。Xcode から実行した版と二重にあると、どちらが呼ばれるか決まらないので、インストール版だけにする。
- ターミナルで試す: `open "clipshelf://open?kind=text"`

### Logi Options+ のアクションリングに登録する
1. Logi Options+ を開き、アクションリング（またはボタンの割り当て）で、空いているスロットを選ぶ
2. アクションに「**ウェブページを開く**」（Open Webpage / Open URL）を選ぶ
3. URL に `clipshelf://open` を入れて保存（種類別のスロットは `clipshelf://open?kind=image` など、スロットごとに作る）
4. ボタンを押して、パネルが開き、選んだものが今使っているアプリに貼られるか確かめる
- メニューの名前や場所は、Options+ の版で違うことがある（この手順は、実機で確かめていない）。`clipshelf://` を受け付けないときは、アクションを「キーストローク」（⇧⌘X）に切り替える（種類別の絞り込みはできなくなる）

## iPhone との受け渡し（AirDrop の代わり）
iPhone で撮った写真・スクショやテキストを、AirDrop なしで Mac に送る（Mac → iPhone も可）。どのネットワークでも使える。
中継サーバー（`clip-relay/`、Cloudflare）には**端末側で暗号化したデータ**だけを置くので、サーバーは中身を読めない。24時間で自動的に消える。

1. 初回: メニューバーのアイコン →「端末のペアリング…」→ 出てきた QR を iPhone のカメラで読み取る（秘密の鍵は QR の `#` 以降に入っていて、サーバーには送られない）
2. iPhone: 開いたページ（`clip-send/`）で「写真・スクショを選んで送る」「テキストを入力して送る」。ホーム画面に追加すると使いやすい（Safari とは保存領域が別なので、ホーム画面のアプリでは、Mac の「ペアリングコードをコピー」で出るコードを最初の画面に貼り付ける）
3. Mac: 届くとメニューバーのアイコンが変わり、パネルに「iPhone」のカードとして出る。ほかの履歴と同じように貼り付けられる（メニューの設定で、届いたらクリップボードにも入れることもできる）
4. どの端末からでもペアリングできる: iPhone・Android・Windows の「ほかの端末をペアリング」で送ったリンクで、ほかの端末をつなげる。ほかの端末で始めたペアリングに Mac が加わるときは、ペアリング画面の「ほかの端末で始めたペアリングに参加する」にリンクを貼り付ける。
5. Windows・Android: Windows 版（`win-clipboard/`）・Android 版（`android-clipboard/`）をペアリングして、同じようにやり取りできる。ペアリング画面の「Windows・Android アプリ用のコードをコピー」を使う（高速モードの鍵が入っているので、自分の端末以外には送らない）
5. Mac → iPhone: カードを右クリック →「iPhone に送る」、または ⌘I（複数選択もできる）。iPhone のページの「Mac から届いたもの」に出る

### ショートカットで1タップ送信（iPhone → Mac・高速モード）
ブラウザを開かずに、iPhone のクリップボード（テキスト・画像）や、写真アプリで選んだ写真を Mac に送る。ペアリング画面の「ショートカット用のアドレス」を、iPhone の「ショートカット」アプリの「URLの内容を取得」（POST）に貼り付けて使う（作り方はペアリング画面に表示される）。

- **① コピーしたものを送る:** 「クリップボードを取得」→「URLの内容を取得」（方法 POST、本文 ファイル＝クリップボード）→「通知を表示」
- **② 共有メニューから送る（コピー不要）:** 「共有シートに表示」をオンにして、「各項目を繰り返す」の中に「URLの内容を取得」（本文 ファイル＝繰り返しの項目）を置く。写真アプリの共有ボタンから、複数枚もまとめて送れる
- **起動のしかた:** ホーム画面のアイコン、コントロールセンター（iOS 18 以降）、アクションボタン（iPhone 15 Pro 以降）、Siri、背面タップ。背面タップは誤動作しやすいので、ホーム画面かコントロールセンターがおすすめ
- ペアリング画面に「最後に受信: 時刻（サーバーに届いてから ○ 秒）」が出るので、スムーズに届いているかを確認できる

- iPhone は、コピーを裏で検知する仕組みを、アプリにも許していない。そのため、完全な自動ではなく、背面タップ（または Action ボタン・コントロールセンター）で1回の操作が必要。
- ショートカットは暗号化できないので、サーバーが受け取った内容を、保存する直前に Mac の公開鍵で暗号化する。保存されるのは暗号文で、Mac だけが読める。サーバーのプログラムは処理の間だけ平文を扱う（`clip-relay/README.md` 参照）。
- Mac → iPhone は、iPhone のページ（`clip-send/`）を開いたときに受け取る（iPhone はページをバックグラウンドで動かせない）。

送れるのはテキストと画像（1件 8MB まで。大きい写真は自動で縮小）。動画は未対応。

## 自分の Mac でビルドして動かす
1. GitHub Desktop でこのリポジトリを取得（更新は「Fetch origin → Pull origin」）
2. 試すとき: `mac-clipboard/ClipShelf.xcodeproj` を Xcode で開いて ▶（Run）
3. 普段使い: GitHub Desktop の「Repository → Open in Terminal」で開いたターミナルで次を実行する。ビルドして「アプリケーション」フォルダに入れ、起動まで行う。
   ```
   sh mac-clipboard/scripts/install.sh
   ```
4. 2回目以降の更新: メニューバーのアイコン →「最新版にアップデート…」を押すだけ（ターミナルが開き、取得 → ビルド → 入れ替えまで自動で行う）
5. ビルドし直してもアクセシビリティの許可が外れないようにする（1回だけ）
   1. Xcode の Settings → Apple Accounts で Apple ID を追加
   2. Manage Certificates… → ＋ → Apple Development
   3. 次を実行する
      ```
      sh mac-clipboard/scripts/setup-signing.sh
      ```

## アップデートが止まったとき
「最新版にアップデート…」は、手元にコミットしていない変更があっても止まらない。変更は「local-backup-日付」というブランチに退避してから最新版にする（消えない。GitHub Desktop の Current Branch から見られる）。中身はルートの `scripts/safe-pull.sh`。
- `fatal: mmap failed` などで止まるのは、リポジトリが **iCloud Drive の中**（デスクトップ・書類を iCloud に同期している）にあるとき。iCloud の外（例: ホームフォルダの `GitHub` フォルダ）に取り直す（GitHub Desktop の File → Clone Repository…）。
- **許可がオンに見えるのに効かない**とき: 署名が変わると、一覧のスイッチは古いアプリへの許可のまま残る。一覧で選んで「−」で削除し、アプリを開き直して許可し直す（install.sh は、署名が変わったときに自動で古い許可を消す）。
- 取り直したあとは、新しい場所で `install.sh` を 1 回実行する。署名の設定（`Config/Local.xcconfig`）は、前の場所から自動で引き継ぐ（なければ Apple ID の証明書から作る）。

## 開発メモ
- Xcode のプロジェクトは `project.yml`（XcodeGen）から GitHub Actions が自動生成してコミットする。設定変更は `project.yml` を編集する。
- 署名は初期値が「このMacで実行（ad-hoc）」。この場合、ビルドし直すたびにアクセシビリティの許可が外れることがある。`scripts/setup-signing.sh` で Apple ID の開発用証明書に切り替えると外れない（`Config/Local.xcconfig` は Git に入らない）。
- 起動時に、同じアプリがすでに動いていれば古いほうを終了する（Xcode 実行版とインストール版の二重起動を防ぐ）。
- 構成:
  - `HotKey.swift`: グローバルショートカット（Carbon）
  - `PasteboardWatcher.swift`: クリップボードの監視
  - `ClipStore.swift`: 保存
  - `StoragePolicy.swift`: 履歴の件数・容量の上限で、どれを消すかの計算、古い画像を軽くする日数の判定（テストあり）
  - `ImageUtil.swift` / `ImageRecompressor.swift`: 画像の変換、古い PNG を JPEG にするか決めて変換（テストあり）
  - `PanelController.swift` / `PanelView.swift`: 下から出るパネル（SwiftUI）
  - `Paster.swift`: 貼り付け（CGEvent で ⌘V を送る）
  - `FrontApp.swift`: 直前に前面だったアプリを覚えて、貼る前にそのアプリを前面に戻す
  - `DeepLink.swift`: URL スキーム `clipshelf://` の解析（テストあり）
  - `SyncCrypto.swift`: iPhone との暗号（`clip-send/` と共通。固定の値で一致をテスト）
  - `Sync.swift`: 中継サーバーとの送受信（WebSocket＋30秒ごとの確認）
  - `PairingWindow.swift`: ペアリング画面（QR）
