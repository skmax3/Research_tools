# 窓割り（Mac アプリ）

27 インチ 4K モニターで、**AI を横に置きながら研究作業をする**ためのウィンドウ配置アプリ。
ショートカット 1 回で、ウィンドウを 1/2・1/3・2/3・1/4・6 分割にきっちり並べる。

- メニューバーに常駐（アイコンは縦に割った四角）。データは外部に送らない。
- 必要環境: macOS 14 Sonoma 以降、Xcode（App Store から無料）。
- 初回に「システム設定 → プライバシーとセキュリティ → アクセシビリティ」で **MadoWari** を許可する（ほかのアプリのウィンドウを動かすのに必要）。

## 3 つの使い方

### 1. AI と並べる（⌃⌥A）
いま作業しているウィンドウ（Word、PDF、ブラウザなど）の横に、AI（初期設定は Claude）のウィンドウを出す。
AI が起動していなければ起動する。操作は作業中のウィンドウに戻るので、そのまま続けられる。
置く側（左／右）と幅（1/4・1/3・2/5・1/2）は設定で変えられる。

### 2. 配置プリセット（⌃⌥1〜9）
「AI ＋ 論文執筆 ＋ PDF」のような並べ方を登録しておき、1 回で全部のウィンドウを並べる。

| 初期のプリセット | 並べ方 |
|---|---|
| ⌃⌥1 AI ＋ 論文・レポート執筆 ＋ PDF | Claude 左 1/3 ｜ Word 中央 1/3 ｜ プレビュー 右 1/3 |
| ⌃⌥2 AI ＋ コード | Claude 左 1/3 ｜ VS Code 右 2/3 |
| ⌃⌥3 AI ＋ 調べもの（6 分割） | Claude 左 1/3 ｜ Safari 中央 1/3 ｜ プレビュー 右上・Finder 右下 |
| ⌃⌥4 資料を読みながら AI に聞く | プレビュー 左 2/3 ｜ Claude 右 1/3 |

- 起動していないアプリは飛ばす（「なければ起動」にチェックした行は起動して並べる）。
- **今の画面の配置を保存**: 手でウィンドウを並べてから、メニューの「今の画面の配置をプリセットに保存」。次の番号（⌃⌥5 など）で呼び出せる。
- 設定画面で、アプリ・場所（一覧から選ぶ／図をドラッグ）・並べる画面・「ほかのアプリを隠す」を変えられる。同じアプリを 2 行入れると、そのアプリの 2 つ目のウィンドウが 2 行目の場所に入る。

### 3. 1 つずつ動かす（ショートカット）
| キー | 動き |
|---|---|
| ⌃⌥← / → | 左（右）半分 → 2/3 → 1/3（押すたびに切り替え） |
| ⌃⌥D / F / G | 左・中央・右 1/3（もう一度押すとその列の上 → 下） |
| ⌃⌥E / T | 左 2/3 ／ 右 2/3 |
| ⌃⌥C | 中央 1/2 → 中央に大きく |
| ⌃⌥↑ / ↓ | 今の列の上半分／下半分（もう一度で横幅いっぱい） |
| ⌃⌥U / I / J / K | 左上・右上・左下・右下 1/4 |
| ⌃⌥↩ | 全体（最大化） |
| ⌃⌥⌘← / → | 左（右）の画面へ、同じ割合のまま移す（MacBook 本体 ⇄ 4K モニター） |
| ⌃⌥⌫ | 元の位置に戻す |
| ⌃⌥W | マス目（12 × 6）をドラッグして好きな場所を指定 |

⌃ = control、⌥ = option、⌘ = command。ウィンドウどうしのすき間（初期 8 pt）は設定で 0〜24 pt に変えられる。
Rectangle など、ほかのウィンドウ整理アプリと同じキーは同時に使えない（使っているならどちらかを止める）。

## 4K モニターの表示設定のおすすめ
「システム設定 → ディスプレイ」で、27 インチ 4K は **「2560 × 1440 相当」**（または一段階広い「3008 × 1692 相当」）にすると、3 列に並べても文字が読みやすい。
窓割りは割合で並べるので、どの解像度でもそのまま使える。

## 自分の Mac でビルドして動かす
1. GitHub Desktop でこのリポジトリを取得（更新は「Fetch origin → Pull origin」）
2. GitHub Desktop の「Repository → Open in Terminal」で開いたターミナルで次を実行する。ビルドして「アプリケーション」フォルダに入れ、起動まで行う。
   ```
   sh mac-window/scripts/install.sh
   ```
3. 出てくる案内で「許可の設定を開く」→ MadoWari をオンにする
4. メニューバーのアイコン →「ログイン時に起動」をオン
5. 2 回目以降の更新: メニューバーのアイコン →「最新版にアップデート…」
6. ビルドし直しても許可が外れないようにする: クリップ棚で `setup-signing.sh` を実行済みなら、install.sh が同じ署名を自動で使う。まだなら `sh mac-window/scripts/setup-signing.sh`（手順はクリップ棚の README の 5 と同じ）

試すだけなら `mac-window/MadoWari.xcodeproj` を Xcode で開いて ▶（Run）でもよい。

## 開発メモ
- Xcode のプロジェクトは `project.yml`（XcodeGen）から GitHub Actions が自動生成してコミットする。設定変更は `project.yml` を編集する。
- 仕様と今後の候補は [SPEC.md](SPEC.md)。
- 構成:
  - `Geometry.swift`: 場所（画面に対する割合）→ ウィンドウの枠の計算、座標変換（テストあり）
  - `Presets.swift`: 配置プリセットの形・初期値（テストあり）
  - `WindowMover.swift`: アクセシビリティ API でウィンドウを読む・動かす、AI と並べる、プリセットの適用・保存
  - `GridSelector.swift` / `GridPicker.swift`: マス目の図（設定画面と ⌃⌥W で共通）
  - `SettingsView.swift`: 設定画面（SwiftUI）
  - `Shortcuts.swift`: ショートカットの一覧（登録と表示で共通）
  - `HotKey.swift`: グローバルショートカット（Carbon。クリップ棚と同じ）
  - `App.swift`: メニューバー
