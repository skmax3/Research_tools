# 窓割り（Mac アプリ）

27 インチ 4K モニターで、**AI を横に置きながら研究作業をする**ためのウィンドウ配置アプリ。
ショートカット 1 回で、ウィンドウを 1/2・1/3・2/3・1/4・6 分割にきっちり並べる。

- メニューバーに常駐（アイコンは縦に割った四角）。データは外部に送らない。
- 必要環境: macOS 14 Sonoma 以降、Xcode（App Store から無料）。
- 初回に「システム設定 → プライバシーとセキュリティ → アクセシビリティ」で **MadoWari** を許可する（ほかのアプリのウィンドウを動かすのに必要）。

## まずはこれだけ：配置パネル（⌃⌥W）
キーを覚えていなくても、**⌃⌥W**（またはメニューバーのアイコン →「配置パネルを開く…」）で、マウスだけで全部できる。

**配置案から並べる**（いくつものウィンドウをまとめて並べる）
1. 上で並べる画面を選ぶ（4K モニター／MacBook 本体）
2. 左の「配置案」から並べ方を選ぶ（3 列・1/3 ＋ 2/3・6 分割・フルスクリーン など。保存したプリセットも出る）
3. 右の「開いているウィンドウ」を、真ん中の枠へ**ドラッグ**して入れる。クリックすると、選んでいる枠（青い線）に順に入る
   - 最初から、手前にあるウィンドウが順に入っている。違うところだけ入れ替えればよい
   - フルスクリーンのウィンドウ、別のデスクトップにあるアプリも一覧に出る
4. **↩**（または「並べる」）でまとめて並ぶ。「プリセットとして保存」で、次から ⌃⌥数字 1 回で同じ並びにできる

**アプリの最小の大きさ（重なりの警告・おすすめの幅）**
アプリには「これ以上狭くできない」幅がある。小さな画面（MacBook 本体）で 3 列にすると、1/3 に入らないことがある。
- 配置パネルを開くと、まだ知らないアプリのウィンドウを**一瞬だけ小さくして最小の大きさを測る**（各アプリ 1 回だけ。すぐ元に戻る）。並べたときにも覚え直す
- 右の一覧に、選んでいる画面での**おすすめの幅**（「1/2 以上」など）が出る。マウスを乗せる・ドラッグすると詳しく出る
- 枠に入らないアプリは、枠が**オレンジ**（隣を細くして並べる）か**赤**（どうしても重なる）になり、最小の幅と枠の幅が出る
- 左の配置案にも、重なるものに ⚠️ が付く
- 覚えた大きさは、設定 →「カーソル・動き方」の「忘れる」で消せる

**手前のウィンドウだけ動かす**（タブを切り替える）: マス目のドラッグか、よく使う場所のボタンで 1 つだけ動かす。

動かすと、画面の真ん中に場所の名前が一瞬出る（どのキーで何が起きたか覚えやすい。設定でオフにできる）。

## 3 つの使い方

### 1. AI と並べる（⌃⌥A）
いま作業しているウィンドウ（Word、PDF、ブラウザなど）の横に、AI（初期設定は Claude）のウィンドウを出す。
AI が起動していなければ起動する。操作は作業中のウィンドウに戻るので、そのまま続けられる。
置く側（左／右）と幅（1/4・1/3・2/5・1/2）は設定で変えられる。

### 2. 配置プリセット（⌃⌥1〜9）
「AI ＋ 論文執筆 ＋ PDF」のような並べ方を登録しておき、1 回で全部のウィンドウを並べる。

| 初期のプリセット | 並べ方 |
|---|---|
| ⌃⌥1 AI ＋ 論文・レポート執筆 ＋ PDF | Claude 左 1/3 ｜ Word 中央 1/3 ｜ プレビュー 右 1/3 |
| ⌃⌥2 AI ＋ コード | Claude 左 1/3 ｜ VS Code 右 2/3 |
| ⌃⌥3 AI ＋ 調べもの（6 分割） | Claude 左 1/3 ｜ Safari 中央 1/3 ｜ プレビュー 右上・Finder 右下 |
| ⌃⌥4 資料を読みながら AI に聞く | プレビュー 左 2/3 ｜ Claude 右 1/3 |

- 起動していないアプリは飛ばす（「なければ起動」にチェックした行は起動して並べる）。
- **今の画面の配置を保存**: 手でウィンドウを並べてから、メニューの「今の画面の配置をプリセットに保存」。次の番号（⌃⌥5 など）で呼び出せる。
- 設定画面で、アプリ・場所（一覧から選ぶ／図をドラッグ）・並べる画面・「ほかのアプリを隠す」を変えられる。同じアプリを 2 行入れると、そのアプリの 2 つ目のウィンドウが 2 行目の場所に入る。

### 3. 1 つずつ動かす（ショートカット）
**左手だけで押せる配置**（⌃⌥ ＋ キーボードの左半分）。右手はマウスやトラックパッドのままでよい。

```
  1〜5 プリセット
  Q 左半分     W 配置パネル   E 左 2/3     R 右半分     T 右 2/3
  A AI と並べる S 入れ替え    D 左 1/3     F 中央 1/3   G 右 1/3
  Z 元に戻す   X 最大化      C 中央       V 整理       B カーソル止め
  ⇥（tab） 隣の画面へ
```

| キー | 動き |
|---|---|
| ⌃⌥Q / R | 左（右）半分 → 2/3 → 1/3（押すたびに切り替え） |
| ⌃⌥D / F / G | 左・中央・右 1/3（もう一度押すとその列の上 → 下） |
| ⌃⌥E / T | 左 2/3 ／ 右 2/3 |
| ⌃⌥C | 中央 1/2 → 中央に大きく |
| ⌃⌥X | 全体（最大化） |
| ⌃⌥⇥ | 隣の画面へ、同じ割合のまま移す（MacBook 本体 ⇄ 4K モニター）。⌃⌥⌘← は左の画面へ |
| ⌃⌥Z | 元に戻す。直前が配置案・プリセット・整理・AI と並べる・入れ替えなら、**動かしたウィンドウ全部と隠したアプリをまとめて戻す** |
| ⌃⌥S | 手前のウィンドウと、右（なければ左）の隣のウィンドウの場所を入れ替える |
| ⌃⌥⇧W / A / S / D | 上・左・下・右の隣のウィンドウへ移る（手前に出す。マウスを使わずに切り替え） |
| ⌃⌥V | この画面を整理（同じアプリのウィンドウはタブにまとめ、手前の 3 個のアプリだけ残してほかを隠す） |
| ⌃⌥W | 配置パネル（マス目のドラッグ・プリセット・AI） |
| ⌃⌥A | AI と並べる |
| ⌃⌥B | 境目でカーソルを止める：オン・オフ |
| ⌃⌥↑ / ↓ | 今の列の上半分／下半分（もう一度で横幅いっぱい）※右手 |
| ⌃⌥U / I / J / K | 左上・右上・左下・右下 1/4 ※右手 |

**もっと楽にする（おすすめ）**: システム設定 → キーボード →「キーボードショートカット…」→「修飾キー」で、**Caps Lock を Control** にする。
⌃ が小指のホームポジション（A の左）に来るので、⌃⌥ を「小指＋親指（⌥）」で押せて、残りの指でキーに届く。

⌃ = control、⌥ = option、⌘ = command。画面の端の余白（初期 0 pt＝端までぴったり）と、ウィンドウどうしのすき間（初期 6 pt）は、設定の「カーソル・動き方」で別々に変えられる。

**キーは自由に変えられる**: 設定 →「ショートカット」で、キーの部分を押してから新しい組み合わせを押す（esc でやめる、⌫ でオフ）。
ほかのショートカットと同じキーにしようとすると、その場で教えてくれる。Rectangle など、ほかのアプリと同じキーは同時に使えない。

## MacBook 本体の画面
4K モニターと同じように並べられる。ショートカットは、ウィンドウのある画面の中で動かす。
- 配置パネルの上で「MacBook 本体」を選ぶと、その画面に並べる。MacBook 本体を選ぶと、最初の配置案は「フルスクリーン」になる
- 配置案の「フルスクリーン」や、プリセットの「全画面」にチェックした行は、並べたあとフルスクリーンにする
- プリセットの「並べる画面」で「MacBook 本体の画面」を選べる。メニューの「今の配置をプリセットに保存」は、マウスのある画面の配置を保存する（フルスクリーンのウィンドウは「全画面」として保存）

## フルスクリーンのウィンドウ
緑のボタンで全画面にしたウィンドウも、そのまま ⌃⌥Q やプリセットで並べられる。窓割りが全画面を解除し、元の画面に戻るのを待ってから並べる（少し時間がかかる）。
解除したくないときは、設定 →「カーソル・動き方」でオフにできる。

## デスクトップ（操作スペース）と組み合わせる
ステージマネージャの代わりに、**作業ごとにデスクトップを分けて、窓割りで並べる**と見やすい。
1. Mission Control（F3、またはトラックパッドを 3 本指で上へ）の右上の「＋」で、デスクトップを増やす（論文・CAD など）
2. システム設定 → キーボード →「キーボードショートカット…」→ Mission Control で、**「デスクトップ 1 へ切り替え」〜** をオンにする（⌃1〜⌃9）
3. 設定 → 配置プリセットの「並べるデスクトップ」でデスクトップ番号を選ぶ。⌃⌥数字 1 回で、そのデスクトップへ切り替えてから並べる
   - そのデスクトップにウィンドウがないアプリは飛ばす（ほかのデスクトップのウィンドウを使うと、macOS がそちらへ切り替えてしまうため）
4. アプリをいつも同じデスクトップで開くには、Dock のアイコンを右クリック → オプション →「割り当て先」

**ほかのアプリを隠す**: 配置パネルの「ほかのアプリを隠す」（初期オン）とプリセットの同じ設定で、並べたアプリ以外を隠す（⌘H と同じ。閉じない）。
ほかの画面・ほかのデスクトップにもウィンドウがあるアプリは、そちらで使っているかもしれないので隠さない。戻すときはメニューの「隠したアプリを全部表示」か、Dock・⌘Tab から。

**この画面を整理（⌃⌥V）**: マウスのある画面の今のデスクトップを片付ける。
1. 同じアプリのウィンドウが 2 つ以上あれば、1 つのウィンドウのタブにまとめる（Finder・プレビュー・Safari など、メニューに「ウインドウ → すべてのウインドウを結合」があるアプリ。閉じないので中身は消えない。設定でオフにできる）
2. 手前（最近使った順）の 3 個のアプリだけ残し、ほかを隠す
残す数は設定 →「カーソル・動き方」で 1〜8 個に変えられる。いま使っているアプリは必ず残り、ほかの画面・ほかのデスクトップにもウィンドウがあるアプリは隠さない。メニューからも使える。

できないこと: デスクトップを新しく作る・ウィンドウを別のデスクトップへ移すことは、macOS がほかのアプリに許していない（14.5 以降は非公開の方法も止められた）。この 2 つは Mission Control で行う（ウィンドウを上のデスクトップへドラッグ）。

## ステージマネージャ
ステージマネージャ（ウィンドウを左の帯にしまって 1 つずつ前に出す機能）がオンだと、アプリを手前に出すたびに前のアプリが左の帯にしまわれ、並べても最後の 1 つしか残らない。
そのため窓割りは、**2 つ以上のアプリをまとめて並べるとき（配置案・プリセット・⌃⌥A）に、ステージマネージャをオフにしてから並べる**。
- 自動でオンには戻さない。戻したいときは、メニューバーのアイコン →「ステージマネージャ」か、コントロールセンターから
- オフにしたくないときは、設定 →「カーソル・動き方」で切り替える

## 境目でカーソルを止める（Dock・メニューバーを出しやすくする）
4K モニターの下に MacBook を置いていると、Dock を出そうとしてカーソルを下に動かしたとき、止まらずに MacBook の画面へ抜けてしまう。
窓割りは、**画面の境目でカーソルを少し（初期 0.4 秒）止める**ので、4K モニター側に Dock が出る。そのまま押し続ければ MacBook 側へ移れる。
- **MacBook から上へ動かすときも、MacBook の上の端（メニューバー）で止まる**。メニューバーを使っているときに、少し上へ動かしただけで 4K へ抜けない
- 初期は「上下だけ」。Dock を左右に置いているなら、設定で「上下左右すべて」にする
- 止める時間は 0.1〜1.5 秒で変えられる。⌃⌥B かメニューでオン・オフ
- ドラッグ中は止めない。BetterDisplay の仮想画面などで画面が重なっていても、画面の途中では止めない
- アクセシビリティの許可（ウィンドウを動かすのと同じ）で動く

## 4K モニターの表示設定のおすすめ
「システム設定 → ディスプレイ」で、27 インチ 4K は **「2560 × 1440 相当」**（または一段階広い「3008 × 1692 相当」）にすると、3 列に並べても文字が読みやすい。
窓割りは割合で並べるので、どの解像度でもそのまま使える。

## 自分の Mac でビルドして動かす
1. GitHub Desktop でこのリポジトリを取得（更新は「Fetch origin → Pull origin」）
2. GitHub Desktop の「Repository → Open in Terminal」で開いたターミナルで次を実行する。ビルドして「アプリケーション」フォルダに入れ、起動まで行う。
   ```
   sh mac-window/scripts/install.sh
   ```
3. 出てくる案内で「許可の設定を開く」→ MadoWari をオンにする
4. メニューバーのアイコン →「ログイン時に起動」をオン
5. 2 回目以降の更新: メニューバーのアイコン →「最新版にアップデート…」
6. ビルドし直しても許可が外れないようにする: クリップ棚で `setup-signing.sh` を実行済みなら、install.sh が同じ署名を自動で使う。まだなら `sh mac-window/scripts/setup-signing.sh`（手順はクリップ棚の README の 5 と同じ）

試すだけなら `mac-window/MadoWari.xcodeproj` を Xcode で開いて ▶（Run）でもよい。

## アップデートが止まったとき
「最新版にアップデート…」は、手元にコミットしていない変更があっても止まらない。変更は「local-backup-日付」というブランチに退避してから最新版にする（消えない。GitHub Desktop の Current Branch から見られる）。中身はルートの `scripts/safe-pull.sh`。
- `fatal: mmap failed` などで止まるのは、リポジトリが **iCloud Drive の中**（デスクトップ・書類を iCloud に同期している）にあるとき。iCloud の外（例: ホームフォルダの `GitHub` フォルダ）に取り直す（GitHub Desktop の File → Clone Repository…）。
- **許可がオンに見えるのに効かない**とき: 署名が変わると、一覧のスイッチは古いアプリへの許可のまま残る。一覧で選んで「−」で削除し、アプリを開き直して許可し直す（install.sh は、署名が変わったときに自動で古い許可を消す）。
- 取り直したあとは、新しい場所で `install.sh` を 1 回実行する。署名の設定（`Config/Local.xcconfig`）は、前の場所から自動で引き継ぐ（なければ Apple ID の証明書から作る）。
