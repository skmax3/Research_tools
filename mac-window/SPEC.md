# 窓割り 仕様メモ

## 目的
27 インチ 4K モニター（＋ MacBook 本体）で、AI（Claude など）を使いながら論文・レポート執筆、コード、資料調べをするときに、
ウィンドウを手で動かす手間をなくす。

## 完成の基準（MVP）
- [x] ショートカットで手前のウィンドウを 1/2・1/3・2/3・1/4・6 分割・最大化に置ける。同じキーの連打で切り替え
- [x] ⌃⌥A で作業中のウィンドウの横に AI のウィンドウを出す（起動していなければ起動）
- [x] ⌃⌥1〜9 の配置プリセット。設定画面で編集、今の配置を保存できる
- [x] ⌃⌥W のマス目で好きな場所に置ける
- [x] 画面間の移動、元に戻す
- [ ] 実機（ユーザーの Mac ＋ 4K モニター）で動作確認

## 決めたこと
- 場所は「使える範囲（メニューバー・Dock を除く）に対する割合」で持つ。解像度の設定を変えても、別の画面でも同じ並びになる。
- すき間は画面の端もウィンドウ間も同じ幅（初期 8 pt）。端は別々に丸めて、隣との間が 1 pt ずれないようにする。
- プリセットは「一番大きい画面」に並べるのが初期値（4K モニターを想定）。「マウスのある画面」も選べる。
- 起動していないアプリは飛ばす。行ごとに「なければ起動」を選べる（AI だけ初期でオン）。
- 修飾キーは ⌃⌥（Rectangle と同じ系統）。キーは左手だけで届く左半分に集める（JIS キーボードにない ` は使わない）。⌃⌥Space は macOS の入力ソース切り替えなので使わない。キーは設定で変えられる（`Shortcut.id` ごとに保存）。
- 境目でカーソルを止めるのは mouseMoved だけ（ドラッグ中は止めないが、位置は覚える）。止めるのは上下の境目、設定で左右も。下へ動かすときは手前の画面の端で止め、上へ動かすときは上の画面の下端に置いて留める（どちらも Dock の出る場所）。
  前の位置は、覚えている位置が動きの量（deltaX/Y）からの逆算と 40pt 以上違えば逆算を使う（古い位置で「越えた」と勘違いして、境目ではない所へ引き戻していた）。
  前と今の位置を両方含む画面があれば越えていないとみなす（仮想画面・ミラーで画面が重なっていても途中で止めない）。境目を越えそうなら境目の 1pt 手前にカーソルを戻し、押し続けて hold 秒たったら通す。0.5 秒押すのをやめたら数え直し。
- フルスクリーンは AXFullScreen を false にして、解除が終わるまで 0.15 秒ごとに確認し、さらにアニメーション分 0.5 秒待ってから動かす。
- まとめて並べるときは、後ろの枠から 1 つずつ（フルスクリーン解除・起動を待って）並べて手前に出す。最後に 1 番の枠が手前になる。フルスクリーン指定は全部並べてから。
- 別のデスクトップにあるウィンドウはアクセシビリティ API で見えないので、アプリ単位で一覧に出し、並べるときにアプリを手前に出して（開き直して）ウィンドウを探す。
- ステージマネージャは、システムの設定 `com.apple.WindowManager` の `GloballyEnabled` を `defaults write` で書き換えて切る（コントロールセンターのボタンと同じ。すぐ反映）。並べ終わってもオンに戻さない（戻すと、また 1 つ以外しまわれるため）。
- URL の対象は「URL を開く直前に前面だったアプリ」。前面の復帰は、macOS 14 の「譲り合い」（`yieldActivation(to:)` → `activate(from:)`）で行い、0.2 秒たっても戻らなければアクセシビリティの `AXFrontmost` でも前面にする（最大 1 秒待つ）。前面になった直後は 0.05 秒おいてから実行する。
- アクセシビリティ API（AXUIElement）で動かす。Chrome 系は AXEnhancedUserInterface を一時的に切って動かす。

## 今後の候補
- ウィンドウを画面の端にドラッグして配置（Rectangle のスナップ）
- プリセットを Space（デスクトップ）や時間帯で自動切り替え
- ブラウザのタブ単位（例: Claude を開いている Safari のウィンドウ）で AI を選ぶ
- 同じ列のウィンドウをまとめて幅変更（境目をドラッグ）
