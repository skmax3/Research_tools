# クリップ棚（Windows）

Windows のタスクトレイ（画面右下）に住んで、**Mac・iPhone・ほかの Windows とクリップボードをやり取りする**アプリ。AirDrop や Handoff の代わりになる。
Mac のクリップ棚（`mac-clipboard/`）・iPhone 用のページ（`clip-send/`）と同じ中継サーバー（`clip-relay/`）を使うので、どの端末から送ったものも、ほかの端末に届く。

- 写真・スクショ・テキストを、**端末で暗号化してから**送る。中継サーバーは中身を読めない（24時間で消える）。
- 履歴の画面は作っていない。届いたものを**クリップボードに入れる**ので、Windows 標準のクリップボード履歴（**Win + V**）にもたまる。
- 必要環境: Windows 10 / 11（64ビット）。.NET などの追加インストールは不要（1つの exe にまとめてある）。
- **まだ実機で試していない。** GitHub の Windows 環境で、暗号のテストとビルドが通ることだけ確認している。

## 入れ方（最初の1回）
1. Mac のクリップ棚を最新版にする（メニューバーのアイコン →「最新版にアップデート…」）
2. Windows で、[最新版のページ](https://github.com/skmax3/Research_tools/releases/tag/clipshelf-win-latest)から `ClipShelfWin.zip` をダウンロードして、展開する
3. `ClipShelfWin.exe` をダブルクリックする
   - 「Windows によって PC が保護されました」と出たら、**「詳細情報」→「実行」**を押す（作者の署名をしていないため。自分で作ったアプリなので問題ない）
4. 最初に出る窓で、ペアリングする
   1. Mac のクリップ棚のメニューバーのアイコン →「端末のペアリング…」
   2. 「**Windows・Android アプリ用のコードをコピー**」を押す
   3. そのコードを、Windows の窓に貼り付けて「ペアリング」（コードは、メモや自分宛てのメッセージなどで Windows に送れる。自分の端末以外には送らない）
5. トレイにアイコンが出れば完了。右クリックで、「Windows の起動時に自動で開始」をオンにしておくと便利

## 使い方
| やりたいこと | 操作 |
|---|---|
| ほかの端末から届いたものを貼る | 届くと通知が出て、**そのまま Ctrl+V で貼れる**（設定「届いたら、すぐクリップボードに入れる」がオンのとき）。Win + V の履歴にも入る |
| 履歴パネルを開く（Mac の ⇧⌘X と同じ） | **Ctrl+Alt+X**、またはトレイのアイコンをダブルクリック。画面の下に、色ラベルつきのカード（テキスト＝青・リンク＝紫・画像＝橙）が並ぶ。←→で選び、**Enter で貼り付け**、Space で複数選択（Enter＝順に貼る／Shift+Enter＝まとめて貼る）、Ctrl+1〜9 で番号の貼り付け、Ctrl+I でほかの端末へ送る、Ctrl+P でピン留め、Delete で削除、Tab で種類の絞り込み、文字を打つと検索。右クリックのメニューもある |
| 履歴の保存 | この PC の `%APPDATA%\ClipShelfWin\history`（300 件・500MB まで。ピン留めは残る）。外部には送らない。トレイの「記録を一時停止する」で止められる |
| 今コピーしたものを、ほかの端末へ送る | **Ctrl+Alt+S**。Mac のパネルや iPhone のページに出る |
| コピーするたびに、自動で送る | トレイの右クリック →「コピーするたびに、ほかの端末へ自動で送る」（最初はオフ。パスワードなども送ってしまうので、気をつける。パスワードマネージャーが「記録しないで」と印を付けたコピーは送らない） |
| 届いたものを、あとから取り出す | トレイの右クリック →「届いたもの」（直近10件） |

送れるのはテキストと画像（1件 8MB まで。大きい画像は自動で JPEG にして縮小する）。エクスプローラーでコピーした画像ファイル（1つだけ）も送れる。動画・そのほかのファイルは未対応。

## 高速モードで届いたもの
iPhone の「ショートカット」から直接送ったもの（`mac-clipboard/README.md` 参照）は、ふつうは Mac だけが開ける。Mac の「Windows・Android アプリ用のコード」には Mac と同じ高速モードの鍵が入っているので、このアプリでも開ける。
iPhone の HEIC 写真は Windows が表示できないことがあるため、その場合は、`ダウンロード\ClipShelf` に保存して、そのファイルをコピーした状態にする。

## 困ったとき
- 届かない・送れない: トレイの右クリックで「状態」を見る。`%APPDATA%\ClipShelfWin\log.txt` に、うまくいかなかった理由が残る。
- 設定は `%APPDATA%\ClipShelfWin\config.json`（自分のユーザーだけが読める場所。外部には送らない）。ペアリングを解除するときは、トレイ →「ペアリング…」→「ペアリングを解除」
- 更新: トレイの右クリック →「最新版をダウンロードするページを開く」で、新しい zip を取って、上書きする

## 開発メモ
- C#（.NET 8、Windows Forms）。外部のライブラリ（NuGet）は使わない。
- ビルドは GitHub Actions（`.github/workflows/win-clipboard.yml`）。`main` に入ると、自動でリリース `clipshelf-win-latest` の zip が更新される。
- 構成:
  - `SyncCrypto.cs`: 暗号（Mac・iPhone と共通。固定の値で一致をテスト）
  - `PairCode.cs`: ペアリングコードの読み取り（テストあり）
  - `RelayClient.cs`: 中継サーバーとの通信（WebSocket＋30秒ごとの確認）
  - `Agent.cs`: 送受信の本体
  - `ClipboardIO.cs`: クリップボードの読み書き
  - `MessageWindow.cs`: クリップボードの変更・ショートカットキーの受け取り
  - `TrayApp.cs` / `PairForm.cs` / `Program.cs`: トレイとペアリングの窓
- テスト: `win-clipboard.Tests/`（`dotnet run --project win-clipboard.Tests`。画面を持たない部分だけ）
